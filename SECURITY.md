# Security Policy

## Supported Versions

The maintained fork starts with the `v3` release line.

| Version | Supported |
| ------- | --------- |
| v3.x    | Yes       |
| v2.x    | No        |
| v1.x    | No        |

## Reporting a Vulnerability

Please report security issues privately through GitHub Security Advisories when available. If advisories are not enabled, open an issue with minimal public detail and request a private contact path.

Do not include exploit details, sensitive logs, or user data in public issues.
